# Decisión

Tenant/tenant_id es canónico para todo contrato nuevo y para la persistencia.
Los nombres Organization publicados no se eliminan en esta versión porque
v0.1.0/v0.2.0 ya son contratos consumibles; se mantienen como aliases delgados
y se documenta su retiro futuro. No existen equivalentes Organization en
Supabase remoto.

El cambio público requiere versión minor v0.3.0. La decisión humana de merge y
la publicación del release quedan fuera de esta unidad.
